# 外贸采购回复撰写技能 v1.0

安装对象：客户背调与采购回复组的“回复撰写成员”。主智能体使用案件管理技能，背调成员按背调设计v1.1执行研究；本技能只负责写作。

本目录采用SKILL.md＋references＋assets格式。按宿主支持的技能导入方式安装整个目录；若只支持提示词，应保留主文件及可访问参考文件。本包是 Skill 文件夹集合，不是平台插件包。导入兼容性、派单和文档工具需在目标平台验证。

主智能体派单时附案件ID、客户原始需求、验收研究包及版本、回复策略、有效我方产品商业资料、语言与输出位置。技能产出TM、邮件、中文对照、依据映射和自检记录，由主智能体生成Word并归档。缺失资料返回具体问题或生成真实的澄清式稿件，不虚构承诺。

此包没有邮箱发送、桌面建档脚本或Word渲染依赖；这些由主智能体及其运行工具提供。安装后先按references/检查清单.md的案例验证，再处理真实客户任务。
