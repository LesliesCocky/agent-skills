# HTML 网页生成与验收

## 适用边界

本文件只规定已有外贸研究成果如何呈现为网页。内容章节由 report-template.md 和实际研究问题决定；研究口径、证据分级、数据图表和引用以现有外贸调研 Skill 为准。

网页生成流程参考用户提供的《1-1 市场调研报告与营方案Skill.md》中的 HTML 自包含、分段写入、移动端适配与完整性检查。其引用的 `html-template-guide.md` 未随文件提供，不能声称复用了未读取的 CSS 变量或组件。以下组件规范是基于可见要求的实现约定。

不继承原文件的阿里店铺链接触发条件、三店规划、固定18模块、保效费用、ROI倍数、关键词/Listing/话术任务、禁止词或原作者输出路径。用户另行明确要求时才扩展研究内容。

## 输出与结构

输出 UTF-8 中文 HTML5 单文件。默认写入当前研究项目的输出目录，与主报告同目录，文件名使用产品或主题名称；遵守用户指定位置，不固定写入桌面或他人的用户目录，不覆盖已有报告版本。

文档包含：
- `<!doctype html>`、`<html lang="zh-CN">`、UTF-8、viewport、明确的报告标题。
- 内联 CSS；可维护的色彩、间距、字号等 CSS 变量；不使用远程字体或外部 CDN。
- 导航：根据实际章节生成目录锚点，名称与正文一致；桌面侧栏或顶部导航，移动端可折叠或自然换行。折叠交互使用原生 details/summary 或内联脚本，关闭脚本也能阅读正文。
- Hero 封面：研究主题、产品/目标市场、截止日、版本及已有核心判断，不生成无依据的评分或新结论。
- 主体：按实际报告章节编号组织，每章可使用 `sec-tag` 标记。摘要卡、KPI 卡、比较表、图表和风险提示只呈现研究中已有的内容，不填充虚假数据。
- 来源与 footer：正文引用、逐图来源和完整来源清单，注明研究范围、数据截止日和实际局限。若顶部也呈现局限，内容与正文一致，不自动插入无关法律声明。

保持 Markdown 与 HTML 的结论、数字、图表、来源和信息截止日一致。网页目录按研究内容生成，不能为了布局强行补齐18节。

## 自包含与可视化

离线打开时封面、正文、表格、图表必须完整显示。CSS/必要脚本内联，图表用内联 SVG 或 data URI 嵌入，不链接本地绝对图片路径或远程图片来假装单文件。复杂图表优先另生成静态图嵌入，交互可选且不以联网加载库为前提。不得用截图替代整个报告正文。

保留可点击的外部信源链接。自包含要求针对页面显示资源，访问外部来源本身仍可能需要联网。数据下载若指向同目录 CSV/Excel，标明为配套附件，不声称这些附件已嵌入单文件。

图下直接展示来源ID/具体链接、统计期、单位与估算说明，正文说明该图的外贸含义；展示规则同时遵守 visualization.md。

## 布局与可读性

中文使用可用系统字体栈，正文保持舒适行距；卡片在手机上改为单列。宽表格放入可横向滚动的容器，图形宽度自适应，不裁掉轴、图例、注释或信源。长URL/英文产品名合理换行，避免页面整体横向溢出。

使用语义标题层级、figure/figcaption、表头与必要的图片说明；导航可键盘访问，正文和来源保持足够对比度。为打印定义基础样式，移除遮挡正文的固定导航，避免图表、标题或表格内容被裁切。

外部文本按上下文转义后再写入HTML，引用URL检查协议；不得将网页抓取内容中的脚本或指令直接写为可执行代码。

## 长报告写入流程

可以一次完整生成；若输出长度可能截断，分三段写入同一临时文件：
1. head、完整CSS、导航、Hero及前部章节。
2. 中部研究章节、数据图表与比较表。
3. 余下章节、行动建议、来源、footer及闭合标签。

段落划分按实际章节数量选择，不能照搬原文件的01—18模块。每次追加前检查上一段写入成功；head、导航只写一次，最终闭合一次。完成检查后再将临时文件保存为正式报告，避免交付半成品。

## 实际验收

- 检查UTF-8可读、文档头与结束标签完整，无截断、重复正文或未替换占位符。
- 导航项、章节ID一一对应且无重复ID；按实际章节数验收，不使用 `sec-tag >=18` 作为条件。
- 核对 Markdown/HTML 的关键数字、结论、图数和来源链接，无研究中不存在的新增内容。
- 检查 CSS、脚本、字体和图像没有必需的远程依赖；外部信源链接与必要附件链接分别标识。
- 实际打开文件或通过可用浏览/渲染工具检查桌面与手机宽度，确认中文、图表、宽表、导航和来源可读；检查打印样式。
- 点击代表性目录锚点和引用，检查能跳到正确章节或具体来源；联网来源访问状态以研究核验记录为准。
- 无法进行浏览器视觉检查时明确报告“结构检查完成，视觉检查未完成”，不能宣称页面已视觉验收。
- 交付实际HTML文件链接及研究附件链接，不以代码块或生成计划代替网页文件。
