# 外贸行业调研报告

默认服务中国出口企业，以“卖什么、卖到哪里、卖给谁、通过什么渠道、能否进入、是否有利润”为主线。用户指定其他出口地或研究用途时相应调整。保留 `$industry-research` 调用名。

## 交付底线

完整调研必须包含实际渲染并嵌入正文的数据图表、逐项可点击信源、来源台账、底层数据，以及可执行的市场开发建议。不能仅交付纯文字、表格、图表建议或一份未关联正文的链接清单。不得把“可以制作图表”当作已完成交付。

默认交付带图 Markdown、同内容 HTML 阅读版、图表文件、图表底层 CSV 和来源台账。HTML 是本地报告文件，不自动发布网站。用户指定其他格式时按要求替换阅读版，保留图表和来源。没有足够可核验数据时交付明确标记的“资料受限初稿”，逐项说明缺失及替代检索结果，不能编造数据以达到图表数量，也不能称为完整报告。

## 1. 开题

读 [research-scope.md](references/research-scope.md)。优先提取产品及规格/材质/用途、出口地与企业角色、目标国家、HS 编码、客户类型、价格带与供应能力。只追问会改变判断且无法推断的信息，不重复询问已知用途。未指定目标国家时先做国家筛选，不自行固定一个国家；产品边界不清时先澄清或明确假设。

## 2. 建立证据和数据集

必须读 [evidence-rules.md](references/evidence-rules.md) 与 [trade-research.md](references/trade-research.md)。先定义产品范围及 HS 口径，再检索；编码是候选时必须注明，不把商品名猜测当海关归类结论。

实际调用可用联网搜索、浏览或数据接口，读原文，记录检索和访问状态。网页摘要、模型记忆和其他 AI 回答不作为已核实信源。优先官方贸易数据、目的国海关/统计局、监管及税则；再补充协会、公司官网、展会和专业研究。用户提供文件同样记录页码与口径。

关键数字、法规、竞争者事实和市场推荐，均在对应句段或表格附直接来源链接或可点击的来源编号；编号关联到具体页面而非机构首页。每张图的来源紧邻图，不依赖报告末尾的总清单。读取不到的页面标为未核实，不伪称已访问。

保存关键数据与来源ID，处理年份、单位、币种、HS版本、报告国/伙伴国、贸易方向及总量/细分口径。对关键结论交叉核验并寻找反例，转载同一来源不计独立印证。无法拿到数据时先尝试替代官方来源或可解释的代理指标；注明代理局限，不推算虚假的市场份额。

## 3. 外贸分析

按 [trade-research.md](references/trade-research.md) 研究需求、国家优先级、中国竞争力、买家渠道、准入与利润约束。通用分析需要时读 [analysis-methods.md](references/analysis-methods.md)。投资估值仅在用户要求时增加。

结论区分已核验事实、企业自述、计算估算、情景和研究判断。国家推荐必须说明适配的产品、客户、进入条件与证据缺口，市场进口大不自动等于适合该企业进入。HS大类无法代表目标细分产品时，不将大类总额写成产品市场规模。

## 4. 制作实际图表

必须读 [visualization.md](references/visualization.md)，先建立图表与数据来源对应关系，再用代码或图表工具实际生成图片/矢量图，并嵌入报告。完整多国调研通常覆盖：进口需求趋势、国家规模与增长对比、供应国竞争、中国份额或变化；按可用数据调整，不机械凑图。单国或专项报告用适合问题的图替代。

有定量分析环境时按 data-analytics 技能执行，有 Excel 交付时使用 spreadsheets；Word/PDF/PPT 按对应技能制作并检查。技能不可用时用可用代码工具生成可核验图表与本地 HTML，不以缺少某插件为由省略图表。不能生成时标记交付未完成并说明限制。

## 5. 写作和验收

读 [report-template.md](references/report-template.md) 确定报告内容，按 [html-generation.md](references/html-generation.md) 生成网页阅读版。网页规范仅负责呈现，研究范围、外贸方法、数据图表与信源规则以本 Skill 为准。先数据和证据，后摘要。正文解释每张图显示什么、对外贸选择意味着什么、有哪些限制。结尾提供优先国家、客户类型、渠道、准入事项和下一步验证动作，不自动发送询盘或联系买家。

验收后才能宣布完成：
- 每个开题关键问题已有答案或明确缺口。
- 图表文件真实存在并在 Markdown/HTML 中显示，打开或渲染检查文字、中文字体、图例、轴、单位和来源可读。
- 每张图有底层数据、来源ID、计算规则，图表与正文数字一致；不把表格和流程图计为数据图表。
- 关键事实逐项引用，来源台账有具体URL/文件页码、数据期、访问日及口径；不能拿机构首页充当数据证据。
- 数据不足、付费壁垒、权限或格式限制明确披露；缺项报告不标为完整。
- 关税及认证核对目的国、原产地、编码、日期与适用条件；区分法定义务、客户要求和自愿认证。
- 国家推荐能追溯到数据和企业能力；价格比较注明贸易术语、规格与日期。
- 实际附上报告、阅读版及附件的可访问链接，不以“已完成”文字代替文件。
